# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and respectful, assume good intent, critique ideas rather than
people, and do not harass anyone. Because this project deals with harmful content, one
extra rule applies everywhere in this repository (issues, pull requests, discussions):
**never post or link harmful images** such as sexual content, gore, abuse or extremist
material. Describe them in words instead.

Report unacceptable behaviour privately to the maintainers through a
[GitHub security advisory](https://github.com/karammm/openmoderate-image-moderation/security/advisories/new)
(it is private and reaches the maintainers directly). Reports are handled confidentially,
and maintainers may remove content or ban participants who violate this code.
